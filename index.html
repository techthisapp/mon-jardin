Accéder à votre jardin

Saisissez votre adresse électronique. Si vous avez déjà un jardin, vous le retrouvez tel que vous l'avez laissé. Sinon, il est créé à la première connexion. La même adresse ouvre toujours le même jardin, sans mot de passe.

Vous recevrez un lien, à ouvrir dans le navigateur. Depuis l'application installée sur l'écran d'accueil, utilisez plutôt un code de reprise, généré depuis une session déjà ouverte, sans passer par le courrier électronique.

Ce champ accepte trois formes : un code de reprise, un lien de connexion collé, ou un code à six chiffres.
